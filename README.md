# AutoLoc

Plateforme de gestion de location de véhicules multi-agences





**Acteurs**



\- Client

\- Agent d'agence

\- Responsable d'agence

\- Administrateur



&#x20;**Cas d'utilisation**



&#x20;Client

\- Consulter les véhicules

\- Réserver un véhicule

\- Consulter ses réservations



&#x20;**Agent d'agence**

\- Gérer les clients

\- Gérer les véhicules

\- Gérer les réservations



&#x20;**Responsable d'agence**

\- Gérer l'agence

\- Suivre les locations



&#x20;**Administrateur**

\- Gérer les utilisateurs

\- Gérer les agences

\- Administrer la plateforme
